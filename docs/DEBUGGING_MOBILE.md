# 手机交互日志

手机问题使用独立诊断脚本，不把诊断代码加入生产阅读器。

运行 `node scripts/build-settings-probe.mjs` 生成
`work/hnr-settings-interaction-probe.user.js`（诊断版本 0.0.5）。

## 手机上操作

1. 在 X 浏览器安装诊断脚本，与现有阅读器一起启用，打开或刷新 HN 页面。
2. 页面底部出现日志工具条。记录自动开始，60 秒后停止；切到后台也会停止。
3. 在记录期间打开设置，尝试一次下拉、一次数字输入和一次滚动。
4. 点击“导出”，发送下载的 `hnr-phone-log-*.json`；下载不可用时点击“复制”。剪贴板不可用会显示只读文本框，可全选复制。
5. 如果浏览器卡死，重新打开浏览器，先停用阅读器、保留诊断脚本，再打开 HN 并导出。文件的 `previous` 包含最近一次有实际操作的已保存日志。
6. 采样完成后可停用或卸载诊断脚本。

## 日志与边界

- 记录触摸/指针开始、结束、取消，点击，焦点进出，输入事件次数，滚动，视口变化，菜单与阅读器实例数量、心跳延迟。
- 记录控件名称/类型、命中元素类型、坐标、disabled/readonly/inert 状态。错误只保留类别、标准错误名、已知 API 名称和行列位置，不保存原始错误消息或堆栈。
- 浏览器提供 JS 堆内存数据时记录数值，否则为 `null`；这些观测不能单独证明内存溢出。
- 不记录输入值、按键内容、正文、Cookie、API Key，不请求网络或自动上传。
- 当前和上一会话各最多 200 条记录，长字段截断；滚动事件限频。通常每 2 秒写一次本地存储，操作前的保存间隔不低于 300ms。
- 本地存储不可用时工具条提示“暂存不可用”，仍可导出当前内存日志。进程被杀或完全冻结时无法继续记录，最后尚未保存的事件可能丢失；没有停止标记只能说明记录中断或尚未结束。
- 0.0.3 优先使用脚本管理器的 `GM_getValue` / `GM_setValue`，避免只依赖页面来源的 localStorage；GM 存储失败时退回页面存储。日志标明实际存储后端，并在页面存储可访问时迁移旧版记录。错误页是否允许 GM API 仍由浏览器决定。
- 60 秒后停止事件采样。导出工具条仍可使用；其观察器只跟踪工作区根节点的插入/移除，确保关闭阅读器后仍可导出。

自动化验证覆盖记录上限、保存节流、中断恢复、下载/复制后备路径和清理；真实 X 浏览器下载与卡顿原因仍需设备日志确认。

- 0.0.4 增加浏览器长任务耗时记录（浏览器支持时），以及错误中的已知 API 名称；无法归属的错误保持空名称，不记录原始消息。该工具不拦截网络，不能据此断定连接错误的原因。

## 阅读器内置调用诊断

当独立日志已确认长任务、却无法归属源码时，运行 `node scripts/build-phone-debug.mjs` 生成 `work/hnr-phone-debug.user.js`。它保持原阅读器名称、namespace 和 document-start 时机，以 0.1.4.5 诊断版本替换原脚本；原有设置无需重建。停用独立 HN 日志脚本，只运行这一份阅读器。工具条日志版本为 0.0.5。

构建阶段通过 TypeScript AST 为阅读器内 GM 请求、GM 存储、focus、scrollIntoView、openSettings 调用插入计时。生产源码和 dist 制品不变，记录固定模块/方法名、同步耗时和是否抛错，不记录调用参数、返回值或请求内容。计时不代表异步请求的全程耗时。日志保存本身的同步延迟单独记录，避免误归属。

0.0.5 还记录浏览器支持的长动画帧脚本耗时、布局耗时，以及诊断制品中的字符位置；不记录脚本原始 URL。错误仅额外允许记录完整匹配“标识符.方法 is not a function”的方法表达式，包含引号或其他文本时不保留。

这是定位故障的本地诊断制品，不是已确认的修复或生产发布。导出日志后可恢复正式版。脚本内置日志增加少量观测开销，真实手机结果需单独核验。

## 已确认的 X 浏览器流读取问题

2026-09-12 的 Android16/X 浏览器真机 CPU 采样显示，浏览器实现的 `ReadableStream.pull()` 同步调用 `mbrowser.GM_readStream()`，在阅读器持续订阅 Firebase 评论更新时阻塞主线程。修复通过检测这一原生桥接口，避免打开实时订阅；有限的流式请求使用文本响应，保留最终结果解析。

`node scripts/build-phone-debug.mjs --reader-only` 生成不带日志和调用计时的 `work/hnr-phone-fix.user.js`，可替换原阅读器安装。临时远程注入验证不等于已经更新手机安装的脚本。真机验证覆盖键盘弹出、数字输入、下拉选择、触摸滚动，以及取消后设置保持原值。
