# ADR-0003：初版使用单一精简 userscript

- 状态：已接受
- 日期：2026-08-16

## 决策

保留 Lite 的 TypeScript 事实源、分域模块、严格检查与构建生成物规则，但 V1 生产只输出一个精简 userscript。不预先复制 Core/Platform/Features 三 Library 发布架构。

## 原因

- 当前功能集明显小于参考项目。
- 多 Library 会增加生成、安装、版本对齐和启动解析成本。
- “功能完整但产品不重”要求优先一个按需初始化的小运行时。

## 重审触发器

只有以下任一证据出现时重审：

- 发布平台硬体积限制；
- 同环境性能 trace 证明单包解析是主要启动成本；
- 可选提取器或 AI SDK 无法在不影响启动的情况下保留。
