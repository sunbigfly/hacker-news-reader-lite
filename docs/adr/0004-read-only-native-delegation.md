# ADR-0004：V1 只读，互动委托给 HN 原生

- 状态：已接受
- 日期：2026-08-16

## 决策

Reader 不重写投票、回复、收藏、隐藏、登录和用户资料。回复入口可以在持续保留 Reader 的左侧宿主载入 HN 原生表单，但表单提交与结果仍完全委托给 HN；阅读器可显示明确返回命令，原生链接的 modifier/new-tab 语义必须保留。

## 原因

- 用户目标是阅读，不是重建 HN 客户端。
- 写操作会引入登录态、CSRF、失败恢复和原生行为兼容成本。
- 保留原生互动可以让阅读器专注于性能和内容理解。

## 后果

不复制参考项目的 action、Composer、bookmark、notification 和账号 owner。
