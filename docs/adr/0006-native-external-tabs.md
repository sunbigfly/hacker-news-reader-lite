# ADR-0006：外链使用浏览器原生新标签

- 状态：已接受
- 日期：2026-08-17
- 取代：ADR-0005

## 决策

HN 外部标题链接与 Reader 的文章命令都直接在浏览器原生新标签打开原始 URL，并使用 `noopener noreferrer`。运行时不再抓取、提取、嵌入、翻译或总结外链文章，也不保留页内文章浮窗。

## 原因

- 保持产品聚焦于评论阅读，减少页内布局与滚动冲突。
- 让 PDF、JS-only、登录态和站点自身导航由浏览器及原站正确处理。
- 去除跨域文章抓取、清洗、缓存和浮窗生命周期的运行时成本与安全面。

## 后果

- 当前 HN/Reader 状态在原标签保留，文章阅读使用独立原生标签。
- Reader 只负责校验显式文章命令的 URL；不会提供文章翻译或文章总结。
- ADR-0005 的提取器决策不再用于生产运行时。
