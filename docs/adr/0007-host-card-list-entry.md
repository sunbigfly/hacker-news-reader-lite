# ADR-0007：宿主列表使用卡片投影并可直接进入 Reader

- 状态：已接受
- 日期：2026-08-17
- 导航范围：已由 ADR-0008 收窄为顶部 Tab/`reply` 宿主导航与 `item` Reader 导航

## 决策

HN 列表保留宿主 DOM、内容顺序和子操作，但由 userscript 可逆地投影为与 Reader 一致的紧凑卡片清单和顶部标签栏。宿主皮肤在 `document-start` 安装，业务 owner 延后到 `DOMContentLoaded`；Tabs 保持单行可水平收纳，用户区保持同行靠右。卡片空白区与标题的无 modifier 主键点击，以及卡片聚焦时的 Enter/Space，直接打开评论 Reader。

受支持的同源故事列表 Tab 使用共享 HN HTML scheduler 请求目标页，并在当前文档内事务替换左侧宿主列表、Footer 与列表上下文；右侧 Reader 和顶栏外壳保持挂载。成功后同步选中态、标题与 history，后退/前进复用同一事务；失败保留当前列表。非故事列表页面、modified 点击和显式新标签继续走原生导航。

Ctrl/Cmd 点击标题保留原生外链语义；投票、用户、hide 和其他写操作子控件不被卡片事件劫持。故事的原生评论数 `item?id=*` 链接与显式 `reader` 命令均进入 Reader，不改写宿主 tab 或 URL。翻译总开关开启时，当前页标题自动批量翻译并复用 30 天缓存；卡片不显示“原文”或翻译命令。

用户滚动宿主接近底部时，读取当前 More 指向的受限同源列表页，把新故事导入现有 itemlist 并接入同一卡片合同。Footer 始终保留在 itemlist 之后；失败时保留原 More 作为手动回退。

## 原因

- 宿主列表与 Reader 使用同一套编辑式排版、中性纸张和橙色强调，进入评论的空间关系更连续。
- 卡片空白区成为大目标，比单个小文本命令更易发现和点击。
- 保留宿主 DOM 与原生互动边界，避免建立第二份列表状态或写操作适配器。

## 后果

- Reader 未打开时会在 `document-start` 安装一份本地宿主样式，在 DOM 就绪后安装列表委托事件。翻译关闭且未进入 More 阈值时仍为零业务网络；其他情况只增加标题批量翻译或当前 More 分页请求，始终零轮询、无全页 MutationObserver。
- `HostScope` 必须完整撤销样式、class、attribute、外链属性和新增命令。
- 列表换页必须使用独立可取消请求与每页投影 scope；切换时取消旧分页、清除 More 去重状态，不得保留断开的行、翻译节点或监听器。
- 卡片点击合同必须同时覆盖空白区/标题打开 Reader、其他子控件不劫持、modifier 外链语义和键盘入口。
