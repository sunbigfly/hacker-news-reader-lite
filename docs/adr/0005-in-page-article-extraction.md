# ADR-0005：在 HN 页内获取并提取外链文章

- 状态：已被 ADR-0006 取代
- 日期：2026-08-16

## 决策

外链文章由 HN userscript 在用户显式触发后，通过匿名 GM HTTP 获取、惰性 DOM 提取和严格清洗，然后投影到 HN 页内的单一浮窗。

## 拒绝的方案

- 通用 iframe：大量站点会被 CSP / `X-Frame-Options` 阻断，且无法稳定翻译与总结。
- 全网 `@match`：扩大 userscript 权限、启动影响和站点兼容面。
- 绕过登录墙/付费墙：超出产品与安全边界。

## 后果

- 只能稳定处理可匿名获取的 HTML/文本；JS-only 和受保护内容必须回退到原站。
- GM HTTP 具有跨域能力，必须执行 URL、重定向、类型、体积、凭据与 HTML 清洗安全门禁。
- 初版提取器保持轻量，使用代表站点验收决定是否引入依赖。
