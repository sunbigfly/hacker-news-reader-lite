# Hacker News Reader Lite 质量门禁

## 1. 证据分层

以下证据必须分开报告：

1. 源码与合同：定义、调用、依赖、fixture 和不变量。
2. 静态检查：ESLint、strict TypeScript、CSS/metadata/权限/敏感信息审计。
3. 测试：单元、合同、fixture、生成物运行时测试。
4. 构建：本地 userscript、生产 userscript、bytes/SHA-256/元数据。
5. 真实浏览器：HN DOM、交互、Network、截图和错误。
6. 性能：同环境 A/B trace、长任务、内存、DOM 和长时稳定性。
7. 发布：版本、提交、远端和安装链接。

低层通过不代表高层已验收。

## 2. 必过静态门禁

- strict TypeScript 零错误。
- 本次变更 TS/JS 的定向 ESLint 零错误。
- 无循环依赖、无未声明全局、无直接编辑生成物。
- 非 host adapter 不得包含 HN CSS selector。
- 非 network descriptor/adapter 不得构造远程 URL 或直接请求。
- 复用目标不得导入 `discourse/`、LinuxDo 专属站点、Composer、MessageBus、WebDAV、notification 或账号 owner。
- userscript metadata 仅匹配 HN，没有全网 `@match`。
- 代码和生成物敏感信息扫描不得命中真实 API Key、Cookie、Authorization 值或本机私有配置。

## 3. 复用门禁

每个复制批次必须产生：

- 源仓库相对路径、当前 commit 和 SHA-256；
- 目标仓库路径；
- 一起复制的测试列表；
- 复制后、改造前的基线结果；
- 改造后的 HN 合同结果；
- 删除/替换的 Discourse/LDP 依赖列表；
- MIT License/归属检查。

复制与改造不得以“测试太难迁移”为由丢弃原不变量。

## 4. 功能门禁

### HN 宿主

- 初始 HN 页的宿主皮肤在首次可见绘制前安装；后续只有允许的顶部 tab 和 `/reply` 替换左侧宿主内容，不重建或卸载已打开的右侧 Reader。顶部只保留 Logo，Tabs 在宽度不足时自动换行且不产生水平滚动，账号区与第一行 Tab 水平对齐，续行 Tab 使用无孤立分隔符的极紧凑行距；Reader 内导入 `submit`/`reply` 时宿主临时扩展到至少 62%，用户主动拖动分隔线时立即解除自动宽度并保存新比例，未拖动则在离开表单后恢复原比例；原生表单内容不得撑宽面板，Reader 未打开时卡片清单居中。
- `new`/`past` 的当前 HN `.topsel > a` 整个可见区域可点，只使用橙色下划线表示选中态；宿主区只静默换入顶部 tab 与 Reader `/reply` 表单，其他 HN 页面不导入宿主。
- 故事评论数、评论永久链和其他 `item?id=*` 无 modifier 主键点击打开 Reader；故事 ID 直接打开，评论 ID 定位所属故事中的真实评论，宿主 tab、内容和 URL 不变。
- 列表页结构未被替换；空白区/标题普通点击进入 Reader，modified 标题点击仍可 new-tab，其他原生链接可用。
- 翻译总开关开启时，当前页标题作为一个交互批次自动翻译并可命中缓存；卡片不显示“原文”或“译题/已翻译”入口。
- 宿主未滚动进入底部阈值时不请求 More；全页、分栏、动态滚动目标和 More 可见性哨兵进入后每次只用页面原生同源请求加载一个分页，同 URL 不重复，与 Reader HN 页面和宿主 tab 共享总并发为 2 的 HN HTML scheduler，切页可取消；一个 Reader 恢复刷新在途时，tab 冷请求不得停留在等待队列。
- 重访已成功载入的只读宿主 tab 时不等待网络即替换缓存内容且不设置忙状态；随后仅发起一次后台重新验证，变化替换保留滚动位置，相同、更新成功和更新失败都显式通知，失败不清空缓存内容。
- 同一 tab 在首次请求未完成时被快速重点，旧请求取消后新请求必须使用新的 scheduler entry；界面不得显示“导航已被新目标替代”，最新一次点击必须成功接管宿主导航。
- 新故事保留 HN 顺序并复用卡片点击、Reader 入口和自动标题翻译；Footer 不复制，首次失败至多自动重试一次，持续失败保留手动 More，最后一页 Footer 成为真正页尾。
- Reader 入口可键盘访问，失败时保留 HN 原生行为。
- 分隔线拖动后宿主/Reader 比例立即更新且下次打开保持；两侧滚动条为独立极细灰色样式，宿主滚动条不进入冻结标题区。
- 底部主题选择会让宿主与 Reader 同时预览；取消共同回滚，保存后共同恢复；显式浅色/深色不受相反系统主题覆盖。
- Reader 成功挂载帖子后立即持久化该 StoryId；刷新或重新打开 HN 会恢复该帖子，并高亮、滚动显露宿主列表中对应卡片；当前 `item?id=*` 目标优先且不会与恢复记录产生双开。
- 阅读器内的投票/回复命令跳回原生位置，没有第二套写 API。

### 评论树

- HN 排序、parent/children、深度、deleted/dead、缺失分支正确。
- 折叠不删 canonical data，重开不重排分支。
- 定位给定 item 时保留必要祖先，高亮只出现一次且可清理。
- API 只补缺失/刷新/实时变更子树；Reader 最多一条 `/updates.json` SSE，无全树默认遍历和定时轮询，关闭时连接与在途增量请求归零。
- 列表点击后无需等待缓存或评论页即可进入 Reader Shell；缓存/DOM 首批投影不超过 48 条，完整树只在首批至少绘制一帧后接管，接管时保持当前评论锚点。
- 全帖预热仅在 Reader 首屏后运行，空闲分片有界，覆盖 API 补全内容；不得产生翻译、AI 或其他网络请求。

### 字体与排版

- 字体显示优化开关默认开启，修改后可即时预览、取消回滚并持久化；关闭时 Reader 不应用内置平滑、描边和阴影规则。
- Blink、Gecko 与 WebKit 使用各自的有界渲染参数；代码块、`kbd`/`samp` 和 SVG 图标不得继承文字描边与阴影。
- 开关只影响 Reader Shadow DOM，不对 HN 宿主页面做全局字体接管。

### 翻译

- 自动翻译开启时，Reader 标题区保留英文原标题并在其下显示中文译题；关闭时隐藏译题，失败时不得覆盖或移除原标题。

- Google 成功、Google -> Microsoft、超长 Microsoft -> Google、双失败四条路径可重复。
- 公共服务失败后不自动转 AI。
- AI 只在用户选择 Profile 后使用。
- 原文/双语/译文切换不改 canonical HTML。
- 代码、链接、引用和保护 token 不变。
- 翻译段落按正文顺序入队并保留独立身份；自定义 AI 在 8,000 字符预算内跨评论合包，公共翻译每包最多 6 段且不超过 2,800 字符预算。多个包可并行，已返回的段落不得等待同包其他段落才回填。
- 宿主与 Reader 共用单一页面级翻译队列；每个包的稳定身份覆盖条目 ID、内容指纹、段落序号和尝试次数。相同文字但来自不同条目的段落可以进入同一显式批次，但不得因 HTTP key 碰撞而丢失任一回填位置。
- 后台预取最多占 5 路，第 6 路必须可供可见/交互任务立即使用；已排队或在途的预取包进入视野时原地晋级并由新调用订阅，不得重发相同网络请求。
- 滚动、虚拟高度更新和新 overscan 窗口只增量追加未请求段落；不取消、不重建任何已在途段落。
- 开始请求后每个待译段落立即显示可视占位；AI SSE 的局部译文每次到达都重绘当前段，完成的段落不等待同评论其他段落。
- 翻译 AI 请求显式关闭推理；502/超时等可恢复错误按包重试一次，最终失败为包内各段显示明确可重试提示，不得留下永不结束的占位。
- 顶部打开 Reader 时挂载并翻译不少于两个当前视口高度的正文；中部滚动时前后各保留至少一屏 overscan，不突破 120 条挂载上限。

### 外链文章

- HN modified 标题点击与 Reader 文章命令均打开浏览器原生新标签。
- 新标签使用 `noopener noreferrer`，Reader 内不创建文章浮窗或正文副本。

### AI 总结

- 全帖与分支使用独立 scope identity 和缓存。
- 讨论引用只指向真实输入 item ID。
- 输入截断和覆盖不完整必须可见。
- 无 Profile、取消、超时、服务错误和缓存命中路径均有合同。

### 离线

- 下载操作先命中译文缓存并补齐当前快照的全部可翻译评论；补齐失败不触发文件下载。
- 离线 HTML 的标题与评论正文分别嵌入下载时已保存的 Reader 标题字体栈和正文字体栈，评论正文同步字号变量；这些字段之外的完整 Settings/AI Key 不得进入离线输入或序列化数据。
- 断网下文字、样式、搜索、折叠、译文切换、总结和 item 锚点可用。
- 远程图片失败不破坏文档。
- 离线 HTML 不含密钥、Cookie、Authorization、GM dump 或安装路径。

## 5. 无障碍门禁

- 右侧嵌入工作区使用具名 complementary，Reader 使用具名 region；设置使用具名 dialog。
- 开启后焦点进入表面，关闭后返回发起控件。
- Escape 只关闭最前层可逃逸表面，不同时销毁 Reader。
- 分支折叠、前后导航、翻译、总结、下载和原站打开可纯键盘执行。
- `prefers-reduced-motion` 禁用非必要动画。

## 6. 性能方法

### 环境

- 使用同一 Chrome 二进制、用户配置、窗口、页面和网络条件。
- 通过同一实例切换 userscript 构建宿主原生 vs 脚本启用对照，不新建替代 profile。
- 主场景使用 4× CPU，各至少 5 组冷/热运行；保留 trace 和原始测量记录。
- 将宿主和 userscript 工作按 initiator/call stack 归因，不把宿主成本算到阅读器。

### 阈值

| 指标 | 要求 |
| --- | --- |
| 未打开 Reader | 翻译关闭且未进入 More 阈值时零业务请求；其他情况仅标题批量翻译/单个 More 分页请求；零轮询、无全页 MutationObserver |
| 1,000 评论冷打开 | 4× CPU 下首个可读屏 <=250 ms |
| 1,000 评论热打开 | 4× CPU 下首个可读屏 <=120 ms |
| 挂载评论 DOM | <=120，包括单巨型根分支 |
| 滚动 | 无脚本引起的持续 >50 ms 长任务，无可见锚点跳动 |
| 稳定空闲 | 当前任务结束后零请求与零持续定时器 |
| 全帖预热 | 每片 <=32 条且主动时间预算 <=8 ms；1,000 条完成后零待执行 idle callback |
| 20 次 Reader 开关 | DOM/事件/Observer/定时器/Object URL 无单调增长 |
| 20 次文章切换 | 旧文章 DOM/请求/会话历史可回收，无单调增长 |
| 强制 GC 堆漂移 | 相对首次关闭基线 <=10% |

阈值未通过时，优先优化热路径、初始化时机、批处理和挂载窗口；不删减 PRD 功能。

## 7. 安全门禁

- 外链 URL 只允许 HTTP(S)，拒绝 userinfo、localhost、回环、link-local、私网与保留 IP/hostname。
- GM HTTP 匿名且不带 Cookie；最终重定向 URL 复验。
- 仅接受 HTML/XHTML/纯文本，默认上限 5 MiB。
- HN/API/文章内容经允许列表清洗；禁止事件属性、`javascript:`、脚本、表单、iframe/object/embed。
- AI base URL 只允许登记的 `/models` 和 `/chat/completions`，不允许业务层提交任意 endpoint。
- 诊断仅显示服务域名、状态和脱敏错误类型，不显示密钥/完整 Authorization。

## 8. 构建与发布门禁

- 本地与生产 userscript 都必须由同一事实源构建。
- 构建输出文件、bytes、SHA-256、metadata 和权限列表。
- 发布前运行生产生成物的运行时合同，不只测 `lite/src`。
- 发布前复核单 userscript 决策；没有硬体积/性能证据时不拆 Library。
- 未经明确授权不提交、不推送、不上传或发布。
